# Mantelzorger (rol)

Bron noemt dit zelf expliciet als rol, geen zelfstandig data-object.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — zorgverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door elke naaste vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan tegelijk werkende/ondernemer zijn |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan Wmo-ondersteuning en parkeerregelingen |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de zorgende persoon |
| Actor expliciet toewijsbaar? | Ja — via aanmelding/registratie mantelzorgondersteuning |

**Definitie:** Persoon die onbetaald langdurig zorgt voor een naaste, met specifieke ondersteuningsregelingen (Wmo) en parkeervrijstellingen.
