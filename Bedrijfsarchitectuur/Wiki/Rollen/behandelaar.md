# Behandelaar (rol)

Kernrol in het zaakgericht werken van de gemeente, expliciet als roltype benoemd in het RGBZ/ZTC2-informatiemodel.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — behandelverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende medewerkers vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan meerdere zaken tegelijk behandelen |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het zaakproces (RGBZ) |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door een medewerker |
| Actor expliciet toewijsbaar? | Ja — per zaak toegewezen |

**Definitie:** Rol die beschrijft wat iemand doet bij de behandeling van een zaak (RGBZ/ZTC2-roltype).
