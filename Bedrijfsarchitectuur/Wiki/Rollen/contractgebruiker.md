# Contractgebruiker (rol)

Zie Contracteigenaar; vier samenhangende, apart benoemde contractbeheerrollen.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — gebruiksrol, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende afdelingen vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan meerdere contracten gebruiken |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het contractbeheerproces |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de gebruikende afdeling |
| Actor expliciet toewijsbaar? | Ja — per contract toegewezen |

**Definitie:** Contractbeheerrol: de interne afdeling of medewerker die daadwerkelijk gebruikmaakt van het gecontracteerde product/dienst.
