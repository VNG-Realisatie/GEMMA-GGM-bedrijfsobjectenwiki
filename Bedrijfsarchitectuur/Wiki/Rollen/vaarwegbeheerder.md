# Vaarwegbeheerder (rol)

De gemeente is zelf vaarwegbeheerder van de meeste Utrechtse stadswateren.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — beheerverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door gemeente, RWS of waterschap vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Nee, doorgaans één vaarwegbeheerder per vaarweg |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het waterbeheer |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door het beherende orgaan |
| Actor expliciet toewijsbaar? | Ja — wettelijk/bestuurlijk toegewezen |

**Definitie:** Verantwoordelijkheid voor het beheer van een vaarweg; kan door meerdere partijen (gemeente, Rijkswaterstaat, waterschap) vervuld worden.
