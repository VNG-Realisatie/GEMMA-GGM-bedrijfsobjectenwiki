# Vergunninghouder (parkeren) (rol)

Specifieke toepassing van belastingplicht binnen het parkeerbelastingenproces.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — vergunningstatus, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door elke aanvrager vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan tegelijk bewoner/ondernemer zijn |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan parkeervergunningproces |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de vergunninghoudende partij |
| Actor expliciet toewijsbaar? | Ja — via vergunningverlening |

**Definitie:** Belastingplichtige aan wie een parkeervergunning is verleend voor het parkeren op een aangewezen locatie.
