# Wettelijk vertegenwoordiger (rol)

Specifieke juridische vertegenwoordigingsrol, te onderscheiden van de generieke rol Indiener; omvat ook de status 'gezagsdrager' uit de BRP-Gezagsverhouding.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — vertegenwoordigingsverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door ouder of voogd vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Nee, doorgaans één wettelijk vertegenwoordiger tegelijk per relatie |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan gezagsverhouding (BW) |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de gezagdragende persoon |
| Actor expliciet toewijsbaar? | Ja — wettelijk/rechterlijk vastgesteld |

**Definitie:** Persoon (doorgaans een ouder) die krachtens gezag namens een minderjarige of onder curatele gestelde optreedt.
