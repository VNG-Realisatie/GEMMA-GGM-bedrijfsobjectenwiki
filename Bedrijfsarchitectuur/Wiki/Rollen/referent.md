# Referent (rol)

Specifieke rol binnen het asiel-nareisproces, los van generieke referentie-/referentienummervelden elders in het GGM.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — hereningsverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Nee, is doorgaans specifiek de persoon in kwestie |
| Eén actor kan meerdere rollen tegelijk vervullen? | Nee, één referent per nareisverzoek |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het nareisproces |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de persoon in Nederland |
| Actor expliciet toewijsbaar? | Ja — via het nareisverzoek |

**Definitie:** Persoon in Nederland bij wie een gezinslid via nareis herenigt; de gemeente toetst de huisvesting.
