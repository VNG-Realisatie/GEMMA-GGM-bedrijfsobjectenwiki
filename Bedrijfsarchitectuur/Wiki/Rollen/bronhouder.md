# Bronhouder (rol)

Cross-cutting rol binnen het rollenmodel van de basisregistraties; de gemeente is zelf bronhouder voor meerdere registraties.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — verantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — gemeente, Kadaster, KvK kunnen deze rol vervullen |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — de gemeente is bronhouder voor meerdere registraties tegelijk |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de basisregistratiewetgeving |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door het bestuursorgaan |
| Actor expliciet toewijsbaar? | Ja — wettelijk toegewezen per registratie |

**Definitie:** Verantwoordelijkheid voor het aanleveren en de kwaliteit van gegevens aan een basisregistratie (BAG, BRP, BRO, WOZ e.a.).
