# Sociaal Raadslid (rol)

Geheel andere betekenis dan de al gedekte rol Raadslid — een laagdrempelige juridische adviesfunctie.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — adviesverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende medewerkers vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan gecombineerd worden met andere adviesfuncties |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het sociaal-juridisch dienstverleningsproces |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door een aangewezen medewerker |
| Actor expliciet toewijsbaar? | Ja — via het adviesloket |

**Definitie:** Juridisch-sociaal adviesloket voor inwoners, niet te verwarren met het raadslid van de gemeenteraad.
