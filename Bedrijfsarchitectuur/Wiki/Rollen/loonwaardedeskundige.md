# Loonwaardedeskundige (rol)

Specifieke, gecertificeerde beoordelingsrol binnen het proces van loonkostensubsidie.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — beoordelingsverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende gecertificeerde deskundigen vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Nee, doorgaans één deskundige per beoordeling |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de loonwaardemethodiek (Participatiewet) |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de gecertificeerde deskundige |
| Actor expliciet toewijsbaar? | Ja — via certificering |

**Definitie:** Gecertificeerde deskundige die volgens een erkende methodiek de loonwaarde van een werknemer vaststelt (Participatiewet).
