# Leerplichtambtenaar (rol)

De leerplichtambtenaar draagt de wettelijke verantwoordelijkheid voor het toezicht op de naleving van de Leerplichtwet. De rol is aan de functie gebonden en wordt door aangewezen ambtenaren vervuld.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — toezicht houden is een ambtelijke verantwoordelijkheid |
| Door meerdere actoren vervulbaar? | Ja — door verschillende aangewezen ambtenaren |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan gecombineerd worden met RMC-functie |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — toezicht op de Leerplichtwet |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door een ambtenaar |
| Actor expliciet toewijsbaar? | Ja — via aanwijzing door het college |
