# Woo-contactpersoon (rol)

Specifieke, wettelijk verankerde rol binnen de Woo-uitvoering.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — aanspreekpuntverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende medewerkers vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan gecombineerd worden met andere functies |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de Woo |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door een aangewezen medewerker |
| Actor expliciet toewijsbaar? | Ja — formele aanwijzing |

**Definitie:** Wettelijk verplicht aanspreekpunt voor vragen over de beschikbaarheid van publieke informatie (art. 4.7 Woo).
