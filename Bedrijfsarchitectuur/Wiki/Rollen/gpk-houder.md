# GPK-houder (rol)

Vergelijkbaar patroon als de al gedekte rollen Huurder/Eigenaar: een gemeentelijk toegekende status met eigen rechten.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — vergunningstatus, geen entiteit |
| Door meerdere actoren vervulbaar? | Nee, is specifiek de kaarthouder zelf |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan tegelijk bewoner/vergunninghouder zijn |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de GPK-toekenning |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de houder |
| Actor expliciet toewijsbaar? | Ja — via de GPK-aanvraag |

**Definitie:** Houder van een gemeentelijk afgegeven gehandicaptenparkeerkaart met specifieke parkeerrechten.
