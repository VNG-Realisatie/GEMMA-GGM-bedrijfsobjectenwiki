# Boswachter (rol)

Specifieke, wettelijk gekaderde toezichtsrol binnen het dierenwelzijnsdomein.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — toezichtsverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door een aangewezen functionaris vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Nee, doorgaans één jachtbevoegdheid per gebied |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de jacht-/faunawetgeving |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de aangewezen functionaris |
| Actor expliciet toewijsbaar? | Ja — via aanwijzing binnen provinciale kaders |

**Definitie:** Gemeentelijke functionaris met jachtbevoegdheid binnen provinciale kaders, relevant voor dierenwelzijnsbeleid.
