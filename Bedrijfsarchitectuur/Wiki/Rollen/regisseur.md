# Regisseur (maatschappelijk vastgoed) (rol)

Bron noemt letterlijk 'partner, regisseur, facilitator, eigenaar/beheerder' als de vier rollen van de gemeente bij maatschappelijke voorzieningen.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — regierol, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — de gemeente vervult deze rol |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan gecombineerd worden met facilitator/eigenaar |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het voorzieningenbeleid |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de gemeente |
| Actor expliciet toewijsbaar? | Ja — beleidsmatig toegewezen |

**Definitie:** Een van vier expliciet benoemde gemeentelijke rollen bij maatschappelijk vastgoed en voorzieningen.
