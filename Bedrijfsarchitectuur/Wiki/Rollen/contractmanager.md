# Contractmanager (rol)

Zie Contracteigenaar; vier samenhangende, apart benoemde contractbeheerrollen.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — aansturingsverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende medewerkers vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan meerdere contracten beheren |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het contractbeheerproces |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door een aangewezen medewerker |
| Actor expliciet toewijsbaar? | Ja — per contract toegewezen |

**Definitie:** Contractbeheerrol verantwoordelijk voor de operationele aansturing van een contract.
