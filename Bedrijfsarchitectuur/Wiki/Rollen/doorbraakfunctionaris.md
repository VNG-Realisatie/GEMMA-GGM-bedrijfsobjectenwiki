# Doorbraakfunctionaris (rol)

Specifieke, herkenbare gemeentelijke functie binnen de overheidsbrede dienstverlening.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — interventieverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende medewerkers vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan gecombineerd worden met casemanager |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan complexe multi-probleemdossiers |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door een aangewezen medewerker |
| Actor expliciet toewijsbaar? | Ja — per dossier toegewezen |

**Definitie:** Functionaris die vastgelopen multi-probleemdossiers doorbreekt door org-overstijgend te interveniëren.
