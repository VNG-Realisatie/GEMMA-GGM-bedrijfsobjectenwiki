# Verwerker (AVG) (rol)

Vaak een externe partij, maar de gemeente sluit zelf de verwerkersovereenkomst en blijft verantwoordelijk.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — verwerkingsverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende externe partijen vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan tegelijk verwerker zijn voor meerdere opdrachtgevers |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de AVG |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door een contractpartij |
| Actor expliciet toewijsbaar? | Ja — via de verwerkersovereenkomst |

**Definitie:** Partij die persoonsgegevens verwerkt namens de gemeente, contractueel vastgelegd in een verwerkersovereenkomst (AVG).
