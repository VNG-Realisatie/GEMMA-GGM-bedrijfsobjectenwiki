# Gebruiksverantwoordelijke (AI) (rol)

De gemeente vervult deze rol zelf bij inzet van AI-systemen in haar processen.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — gebruiksverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — elke organisatie die AI inzet kan deze rol vervullen |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan tegelijk aanbieder zijn bij eigen ontwikkeling |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de AI-verordening |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de gebruikende organisatie |
| Actor expliciet toewijsbaar? | Ja — de gemeente is zelf gebruiksverantwoordelijke |

**Definitie:** Organisatie die een AI-systeem onder eigen verantwoordelijkheid gebruikt (EU AI-verordening).
