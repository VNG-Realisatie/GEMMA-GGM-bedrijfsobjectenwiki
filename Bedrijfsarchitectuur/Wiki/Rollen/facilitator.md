# Facilitator (maatschappelijk vastgoed) (rol)

Zie Regisseur; vier samenhangende gemeentelijke rollen in het voorzieningenbeleid.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — faciliterende rol, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — de gemeente vervult deze rol |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan gecombineerd worden met regisseur/eigenaar |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het voorzieningenbeleid |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de gemeente |
| Actor expliciet toewijsbaar? | Ja — beleidsmatig toegewezen |

**Definitie:** Een van vier expliciet benoemde gemeentelijke rollen bij maatschappelijk vastgoed: het mogelijk maken van initiatieven van derden.
