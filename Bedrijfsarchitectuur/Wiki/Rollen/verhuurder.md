# Verhuurder (rol)

Tegenhanger van de reeds gedekte rol Huurder, met eigen wettelijke vergunningplicht.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — verhuurverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door natuurlijk persoon, corporatie of belegger vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan tegelijk eigenaar zijn |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de verhuurvergunning |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de verhurende partij |
| Actor expliciet toewijsbaar? | Ja — via de vergunningverlening |

**Definitie:** Partij onderworpen aan de vergunningvoorwaarden voor goed verhuurderschap (huisvestingsverordening).
