# Rechthebbende (rol)

Expliciet onderscheiden van Eigenaar in de BRK-catalogus; relevant voor onder meer OZB/WOZ.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — rechtspositie, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende typen rechthebbenden vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan meerdere zakelijke rechten combineren |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het kadaster/BRK |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de rechthebbende partij |
| Actor expliciet toewijsbaar? | Ja — via kadastrale registratie |

**Definitie:** Houder van een zakelijk recht (eigendom, erfpacht, opstal, vruchtgebruik) op een onroerende zaak, breder dan de rol Eigenaar (BRK).
