# Pachter (rol)

Persoon die een pachtovereenkomst heeft met de eigenaar van een perceel voor het gebruik als landbouwgrond. Verwant aan maar te onderscheiden van de reeds gedekte rollen [[Wiki/Rollen/erfpachter|Erfpachter]] (zakelijk recht) en [[Wiki/Rollen/huurder|Huurder]] (gebruik tegen tegenprestatie, niet specifiek landbouwgrond): pacht is een eigen overeenkomstvorm gericht op agrarisch gebruik.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — gebruiksrecht op grond van een pachtovereenkomst, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door elke natuurlijke of rechtspersoon vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Ja — kan tegelijk eigenaar van ander perceel zijn |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan de pachtovereenkomst |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de pachtende partij |
| Actor expliciet toewijsbaar? | Ja — via de pachtovereenkomst |
