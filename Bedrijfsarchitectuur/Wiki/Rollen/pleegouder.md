# Pleegouder (rol)

Specifieke verzorgingsrol binnen de jeugdbescherming, contractueel afgebakend.

## Criteria-toetsing (Business Role)

| Vraag | Antwoord |
|---|---|
| Verantwoordelijkheid i.p.v. entiteit? | Ja — verzorgingsverantwoordelijkheid, geen entiteit |
| Door meerdere actoren vervulbaar? | Ja — door verschillende personen vervulbaar |
| Eén actor kan meerdere rollen tegelijk vervullen? | Nee, doorgaans één pleeggezin per kind tegelijk |
| Gekoppeld aan taken/bevoegdheden/verantwoordelijkheden? | Ja — gekoppeld aan het pleegcontract (Jeugdwet) |
| Geen eigen identiteit, door actor vervuld? | Ja — vervuld door de pleegouder |
| Actor expliciet toewijsbaar? | Ja — via het pleegcontract |

**Definitie:** Persoon die de verzorging en opvoeding van een pleegkind op zich neemt, contractueel vastgelegd in een pleegcontract (Jeugdwet).
